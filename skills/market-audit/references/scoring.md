# market-audit — 採点方式・提案分類・収益試算・競合比較表

## フェーズ3：統合と採点

### 3.1 採点方式

採点材料が欠けるカテゴリは未採点とし、全カテゴリがそろうまで総合点を保留します。全カテゴリがそろった場合は加重平均で総合マーケティングスコアを算出します。

```
マーケティングスコア = (
    コンテンツスコア     × 0.25 +
    コンバージョンスコア × 0.20 +
    SEOスコア            × 0.20 +
    競合スコア           × 0.15 +
    ブランドスコア       × 0.10 +
    成長スコア           × 0.10
)
```

**スコアの解釈：**

| 点数 | 評価 | 意味 |
|---|---|---|
| 85〜100 | A | 優秀 — 細部の最適化のみ |
| 70〜84 | B | 良好 — 改善余地が明確にある |
| 55〜69 | C | 平均的 — 埋めるべき差が大きい |
| 40〜54 | D | 平均以下 — 抜本的な見直しが必要 |
| 0〜39 | F | 危機的 — マーケティングの土台に問題がある |

### 3.2 改善提案の分類

各サブエージェントの提案を集約し、次の3つに分類します。`REPORT-DATA.json` では順に `quick_wins`、`medium_term`、`strategic` に入れます。

**クイックウィン**（着手2週間以内、低工数・高効果）

- 見出しとCTAの文言修正
- 不足しているメタディスクリプションの追加
- CTA付近への信頼シグナルの追加
- リンク切れ・画像切れの修正
- 建設業の場合：建設業許可番号の常時表示、電話番号のヘッダー固定

**中期施策**（1〜4ヶ月、中工数・高効果）

- 料金・費用ページの再設計
- 比較・「他社との違い」ページの新規作成
- 資料請求用のリードマグネット（無料提供資料）作成
- メールシーケンスの導入
- ランディングページのA/Bテスト設計

**戦略施策**（3〜6ヶ月、高工数・変革的効果）

- コンテンツマーケティング戦略の全面見直し
- SEOのコンテンツギャップ解消キャンペーン
- ファネル全体の再設計
- ブランドの再定義
- 新規集客チャネルの開拓

### 3.3 収益インパクトの試算

案件の実績・期間・出典と必要な計算式は `../../market/references/revenue-model.md` に従う。サイトURLだけの監査では収益額は未試算とし、観察した導線と次に測る指標で施策を説明する。シナリオ試算を依頼された場合は、仮定した値、計算式、成約に至るまでの想定期間を併記する。

### 3.4 競合比較表

競合サブエージェントが競合を特定できた場合は、比較表を含めます。

```markdown
| 評価項目 | [対象社] | 競合A | 競合B | 競合C |
|---|---|---|---|---|
| 見出しの明確さ | 6/10 | 8/10 | 5/10 | 7/10 |
| 価値提案の強度 | 5/10 | 7/10 | 6/10 | 8/10 |
| 信頼シグナル | 7/10 | 9/10 | 4/10 | 6/10 |
| CTAの効果 | 4/10 | 8/10 | 6/10 | 7/10 |
| 費用情報の明確さ | 6/10 | 7/10 | 8/10 | 5/10 |
| コンテンツの厚み | 5/10 | 9/10 | 3/10 | 6/10 |
```

建設業の場合は、以下の行を追加してください。

```markdown
| 施工事例の件数 | 12件 | 80件 | 5件 | 40件 |
| 建設業許可の明示 | なし | あり | あり | なし |
| Googleクチコミ | 3.8（12件） | 4.5（86件） | 4.1（7件） | 4.2（33件） |
| 対応エリアの明確さ | 県単位 | 市区町村単位 | 記載なし | 市区町村単位 |
```
