# 出力先フォルダの規則（全スキル共通）

## 基本ルール

生成した成果物ファイルは、カレントディレクトリ直下に直接置くのではなく、**分析対象のドメイン名のフォルダ**に格納する。

1. 実行時の `<url>` 引数からホスト名を取り出す（例：`https://g-wic.jp/` → `g-wic.jp`。`www.` は除去する）
2. カレントディレクトリ直下に、そのホスト名のフォルダが無ければ作成する
3. 生成する全ファイル（`MARKETING-AUDIT.md`、`COMPETITOR-REPORT.md`、`CLIENT-PROPOSAL.md` 等）は、ファイル名自体は変えずにそのフォルダ内に保存する
4. 他スキルの結果を取り込む場合（`/market report`、`/market proposal` が既存の監査結果を参照する場合など）も、同じドメインフォルダの中を確認する

## URLを引数に取らないコマンドの場合

`/market emails <工事種別>`、`/market social <工事種別>`、`/market launch <サービス>` など、URLを直接受け取らないコマンドは以下の優先順で判断する。

1. カレントディレクトリ直下にドメイン名フォルダが**1つだけ**存在する場合は、そこに格納する
2. 複数存在する場合は、直近の分析ファイルの更新日時が最も新しいフォルダに格納する
3. ドメイン名フォルダが1つも無い場合は、カレントディレクトリに直接保存し、その旨をユーザーに一言伝える

## 出力先の例

```
g-wic.jp/
  MARKETING-AUDIT.md
  COMPETITOR-REPORT.md
  CLIENT-PROPOSAL.md
```

## 対象外

このプラグイン自体のファイル（`skills/`、`agents/`、`.claude-plugin/` 等）には適用しない。分析対象ごとに生成される成果物のみが対象。
