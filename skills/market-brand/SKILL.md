# ブランドボイス分析・ガイドライン生成

## このスキルの目的

利用可能なすべてのチャネルからブランドの文体・トーン・メッセージを分析し、実務で使えるブランドボイス・ガイドラインを作成します。ブランドがどう語っているかを調べ、傾向と不統一を洗い出し、誰が書いても一貫性を保てる指針にまとめます。

**出力言語はすべて日本語です。日本語特有の文体要素（敬体・常体、敬語レベル、一人称・二人称）を必ず分析対象に含めてください。**

## 使う場面

- ブランドの文体を把握・文書化したいとき
- 社内・外注先・代理店に渡すトンマナ資料が必要なとき
- チャネル間で表現を統一したいとき
- ブランドを刷新・整理したいとき
- 競合とのトーンの違いを知りたいとき
- `/market brand <url>` または `/market brand` が実行されたとき

## 日本語で必ず見る5つの軸

1. 硬い ←→ 柔らかい
2. 真面目 ←→ 遊び心
3. 専門的 ←→ 平易
4. 控えめ ←→ 大胆
5. **敬語レベル**（常体／です・ます／いたします・ございます／尊敬謙譲の4段階）

**一人称（弊社／当社／私たち）の揺れ**と**敬体・常体の混在**は、日本語サイトで最も目につく不統一です。必ず点検してください。

## スクリプトの場所

同梱のPythonスクリプトは、導入方法によって置き場所が変わります。実行前に次の2行でパスを解決してください。

```bash
MARKET_SCRIPTS="${CLAUDE_PLUGIN_ROOT:+$CLAUDE_PLUGIN_ROOT/skills/market/scripts}"
[ -d "$MARKET_SCRIPTS" ] || MARKET_SCRIPTS="$HOME/.claude/skills/market/scripts"
```
