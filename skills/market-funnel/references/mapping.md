# market-funnel — ファネル型の判定と導線の可視化

## フェーズ1：ファネルの発見とマッピング

### 1.1 ファネル型の判定

サイトがどのファネル型かを判定します。

| ファネル型 | ビジネスモデル | 標準的な段階 | 重要指標 |
|---|---|---|---|
| **問い合わせ型（建設・リフォーム）** | 工務店、リフォーム、外構、塗装 | サイト訪問 → 問い合わせ → 現地調査 → 見積提出 → 契約 | 問い合わせ→成約率 |
| **リード獲得型** | サービス業、代理店、BtoB | ランディングページ → フォーム → サンクスページ → 追客 → 商談 | リード→受注率 |
| **SaaSトライアル型** | SaaS製品 | トップ → 料金 → 登録 → オンボーディング → 有料化 | トライアル→有料転換率 |
| **デモ申込型** | 法人向けSaaS | トップ → 機能 → デモ申込 → 商談 → 受注 | デモ→受注率 |
| **EC型** | ネットショップ | 商品ページ → カート → 決済 → アップセル → 完了 | カート→購入率 |
| **セミナー型** | 講座、コーチ、SaaS | 申込 → 確認 → リマインド → 開催 → 提案 → 決済 | セミナー→成約率 |
| **審査・申込型** | 高単価サービス、プログラム | 案内ページ → 申込フォーム → 審査 → 面談 → 受入 | 申込→受入率 |
| **会員型** | 会員制、コミュニティ | 着地 → 無料体験 → 参加 → 有料会員 | 無料→有料転換率 |
| **コンテンツ型** | メディア、出版 | ブログ → メール登録 → 追客 → 有料コンテンツ → 購読 | 読者→購読者率 |

### 1.2 ファネル各段階の記録

ファネル上の各ページについて、以下を記録します。

```
段階 [#]: [ページ名]
  URL       : [url]
  ページ種別: [着地/サービス紹介/費用/カート/決済/フォーム/サンクス]
  主要行動  : [このページでユーザーに取ってほしい行動]
  次の段階  : [次に進むべきページ]
  離脱地点  : [代わりに離脱してしまう可能性がある箇所]
  摩擦要因  : [動きを鈍らせる・迷わせる要素]
  信頼要素  : [安心感を与える要素]
  読込速度  : [ページの重さから推定]
```

### 1.3 ファネル図の作成

導線をアスキー図で可視化します。

```
訪問者の導線マップ
==================

流入元
  |
  v
[トップページ] ─── 訪問者の100%
  |
  v
[施工事例ページ] ─── 約35%が閲覧
  |
  v
[お問い合わせフォーム] ─── 約4%が到達
  |
  v
[問い合わせ送信] ─── 約1.2%が送信
  |
  v
[現地調査] ─── 約0.6%が実施
  |
  v
[見積提出] ─── 約0.5%
  |
  v
[契約] ─── 約0.15%が成約

全体：訪問者→成約 0.15%
```

このテンプレートは、実際に発見したファネル構成に合わせて調整してください。
