# market-funnel — 指標・訪問者あたり粗利・型別ベンチマーク

## フェーズ3：ファネル指標とベンチマーク

### 3.1 主要指標

以下を算出（不明な場合は業界ベンチマークから推定）します。

```
ファネル指標
============

流入指標:
  月間訪問数  : [推定またはユーザーに確認]
  流入経路    : [自然検索%, 広告%, 参照%, 直接%, SNS%]

転換指標（建設業の標準値）:
  訪問 → 問い合わせ    : [X]%（目安 0.5〜2.0%）
  問い合わせ → 現地調査: [X]%（目安 40〜60%）
  現地調査 → 見積提出  : [X]%（目安 80〜90%）
  見積提出 → 契約      : [X]%（目安 20〜35%）
  訪問 → 契約（全体）  : [X]%（目安 0.05〜0.3%）

収益指標:
  平均受注単価      : [X]万円
  粗利率            : [X]%
  顧客生涯価値（LTV）: [X]万円（メンテ・追加工事・紹介を含む）
  顧客獲得単価（CAC）: [X]万円
  LTV:CAC 比率      : [X]:1（目標 3:1 以上）
  訪問者あたり粗利   : [X]円

関与指標:
  1訪問あたり閲覧ページ数: [X]
  平均滞在時間          : [X]分
  直帰率                : [X]%（目安 30〜60%）
```

### 3.2 訪問者あたり粗利の計算

ファネル最適化において最重要の指標です。

```
訪問者あたり粗利 = 月間粗利 ÷ 月間訪問数

例）建設業（外壁塗装）
  月間3,000訪問 × 訪問→成約率0.15% = 月4.5件
  4.5件 × 平均受注単価120万円 × 粗利率35% = 月間粗利 189万円
  訪問者あたり粗利 = 1,890,000円 ÷ 3,000 = 630円/訪問

問い合わせ率を1.0%から1.5%に改善した場合:
  月間3,000訪問 × 0.15%→0.225% = 月6.75件
  6.75件 × 120万円 × 35% = 月間粗利 283万円
  訪問者あたり粗利 = 945円/訪問
  粗利増 = 月94万円 = 年1,128万円
```

**注意：** 建設業は商談期間が数ヶ月〜1年に及ぶため、改善施策の効果が売上に表れるまで**3〜6ヶ月のタイムラグ**があります。試算には必ず期間を併記してください。

この枠組みで、すべての改善提案の効果を金額に換算します。

### 3.3 ファネル型別のベンチマーク

| ファネル型 | 良好 | 優秀 | 卓越 |
|---|---|---|---|
| 問い合わせ型・訪問→問い合わせ（建設） | 0.5〜1.0% | 1.0〜2.0% | 2.0〜3.0% |
| 問い合わせ型・問い合わせ→成約（建設） | 10〜20% | 20〜30% | 30〜45% |
| リード獲得型（フォーム） | 3〜5% | 5〜10% | 10〜20% |
| SaaS無料トライアル | 2〜5% | 5〜10% | 10〜15% |
| トライアル→有料 | 10〜15% | 15〜25% | 25〜40% |
| EC（閲覧→購入） | 1〜3% | 3〜5% | 5〜8% |
| カート→購入 | 50〜60% | 60〜70% | 70〜80% |
| セミナー申込 | 20〜40% | 40〜55% | 55〜70% |
| セミナー参加 | 30〜40% | 40〜55% | 55〜65% |
| セミナー→成約 | 2〜5% | 5〜10% | 10〜20% |
| デモ→受注 | 15〜25% | 25〜40% | 40〜60% |
