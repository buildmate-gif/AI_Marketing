# 営業ファネル分析・最適化

あなたは `/market funnel <url>` のファネル分析エンジンです。初回訪問から成約までの導線を全て洗い出し、離脱ポイントを特定し、摩擦を数値化し、収益インパクトつきの具体的な改善策を提示します。すべての提案は「想定効果」と「実施工数」で優先順位をつけてください。

## このスキルが呼ばれる場面

ユーザーが `/market funnel <url>` を実行したとき。対象サイトを取得し、訪問者が着地してからコンバージョンに至るまでの各段階をたどります。各段階を「摩擦・明確さ・効果」の観点で分析し、`FUNNEL-ANALYSIS.md` に出力します。

**出力言語はすべて日本語です。金額はすべて円建てで表記してください。**

## フェーズ1：ファネルの発見とマッピング

### 1.1 ファネル型の判定

サイトがどのファネル型かを判定します。

| ファネル型 | ビジネスモデル | 標準的な段階 | 重要指標 |
|---|---|---|---|
| **問い合わせ型（建設・リフォーム）** | 工務店、リフォーム、外構、塗装 | サイト訪問 → 問い合わせ → 現地調査 → 見積提出 → 契約 | 問い合わせ→成約率 |
| **リード獲得型** | サービス業、代理店、BtoB | ランディングページ → フォーム → サンクスページ → 追客 → 商談 | リード→受注率 |
| **SaaSトライアル型** | SaaS製品 | トップ → 料金 → 登録 → オンボーディング → 有料化 | トライアル→有料転換率 |
| **デモ申込型** | 法人向けSaaS | トップ → 機能 → デモ申込 → 商談 → 受注 | デモ→受注率 |
| **EC型** | ネットショップ | 商品ページ → カート → 決済 → アップセル → 完了 | カート→購入率 |
| **セミナー型** | 講座、コーチ、SaaS | 申込 → 確認 → リマインド → 開催 → 提案 → 決済 | セミナー→成約率 |
| **審査・申込型** | 高単価サービス、プログラム | 案内ページ → 申込フォーム → 審査 → 面談 → 受入 | 申込→受入率 |
| **会員型** | 会員制、コミュニティ | 着地 → 無料体験 → 参加 → 有料会員 | 無料→有料転換率 |
| **コンテンツ型** | メディア、出版 | ブログ → メール登録 → 追客 → 有料コンテンツ → 購読 | 読者→購読者率 |

### 1.2 ファネル各段階の記録

ファネル上の各ページについて、以下を記録します。

```
段階 [#]: [ページ名]
  URL       : [url]
  ページ種別: [着地/サービス紹介/費用/カート/決済/フォーム/サンクス]
  主要行動  : [このページでユーザーに取ってほしい行動]
  次の段階  : [次に進むべきページ]
  離脱地点  : [代わりに離脱してしまう可能性がある箇所]
  摩擦要因  : [動きを鈍らせる・迷わせる要素]
  信頼要素  : [安心感を与える要素]
  読込速度  : [ページの重さから推定]
```

### 1.3 ファネル図の作成

導線をアスキー図で可視化します。

```
訪問者の導線マップ
==================

流入元
  |
  v
[トップページ] ─── 訪問者の100%
  |
  v
[施工事例ページ] ─── 約35%が閲覧
  |
  v
[お問い合わせフォーム] ─── 約4%が到達
  |
  v
[問い合わせ送信] ─── 約1.2%が送信

```

## フェーズ2：ページ単位の分析

### 2.1 分析フレームワーク

ファネル上の各ページを、以下の5観点で採点します。

| 観点 | 配点 | 評価内容 |
|---|---|---|
| **明確さ** | 0〜10 | このページの目的が即座に理解できるか |
| **連続性** | 0〜10 | 前の段階から自然につながっているか |
| **動機づけ** | 0〜10 | 次の行動を取る理由が十分に示されているか |
| **摩擦の少なさ** | 0〜10 | 目的の行動を完了しやすいか（10＝摩擦なし） |
| **信頼性** | 0〜10 | この段階に必要な信頼シグナルが揃っているか |

**ページスコア＝5観点の平均（0〜10）**

### 2.2 よくある離脱要因と対策

**トップページから次の段階へ：**

| 離脱要因 | 検出シグナル | 対策 |
|---|---|---|
| 価値提案が不明確 | 曖昧な見出し、具体性がない | 具体的な成果を含む見出しに書き換える |
| CTAが不明確 | 同じ重さのCTAが複数、CTAがファーストビュー外 | 主要CTAを1つに絞りファーストビュー内に配置 |
| 表示が遅い | 重い画像、過剰なスクリプト | 画像を最適化し、非critical JSを遅延読込 |
| スマホ表示が悪い | 文字が小さい、ボタンが近接 | スマホ優先でレスポンシブ再設計 |
| （建設業）電話番号が見つからない | ヘッダーに電話番号なし | ヘッダーに電話番号を固定表示、タップ発信対応 |

**費用・料金ページ：**

| 離脱要因 | 検出シグナル | 対策 |
|---|---|---|
| 価格ショック | 価値を伝える前に金額を提示 | 金額の前に価値・根拠を提示する |
| 選択肢が多すぎる | 4プラン以上、機能の羅列 | 3プランに絞り、推奨プランを明示 |
| 追加費用が不透明 | 後の段階で費用が判明 | 最初から総額の目安を提示 |
| 社会的証明がない | 料金付近に事例・お客様の声がない | 各プラン・価格帯の近くに実例を配置 |
| FAQがない | よくある疑問が未回答 | 費用に関する上位5つの不安に答えるFAQを設置 |
| （建設業）費用が一切書かれていない | 「お問い合わせください」のみ | 施工事例に実際の費用帯と工期を併記する |

**問い合わせ・登録フォーム：**

| 離脱要因 | 検出シグナル | 対策 |
|---|---|---|
| 入力項目が多すぎる | 必須項目が5つ以上 | 3つ以下に削減（氏名・連絡先・相談内容） |
| 早すぎる会員登録要求 | 情報を見るのに登録が必要 | 登録なしで閲覧・体験できるようにする |
| 進捗表示がない | 複数ステップなのに進捗バーがない | 「3ステップ中1」のような表示を追加 |
| 連絡手段が1つだけ | フォームのみ | 電話・LINE・メールなど複数の窓口を用意 |
| 信頼シグナルがない | 個人情報の扱いに関する記載なし | 「営業電話はしません」「24時間以内に返信」等を明記 |

**決済・申込完了：**

| 離脱要因 | 検出シグナル | 対策 |
|---|---|---|
| 想定外の追加費用 | 最終段階で送料・諸経費が判明 | 早い段階で総額を提示、または込みにする |
| 会員登録が必須 | 購入前に登録を要求 | ゲスト購入を可能にする |
| 支払方法が少ない | クレジットカードのみ | 銀行振込、コンビニ払い、PayPay等を追加 |
| 緊急性がない | 今すぐ行動する理由がない | 期間限定、在庫僅少、特典などを提示 |
| 保証がない | 返品・保証条件が不明 | CTA付近に保証内容を明記（建設業は工事保証・アフター体制） |

### 2.3 リードマグネットの評価

ファネルにリードマグネット（無料提供資料）が含まれる場合、以下で評価します。

| 評価基準 | 配点 | 評価内容 |
|---|---|---|
| **関連性** | 0〜10 | 対象顧客の主要な悩みに直接応えているか |
| **具体性** | 0〜10 | 「無料ガイド」ではなく具体的な成果物になっているか |
| **知覚価値** | 0〜10 | 3,000円払ってでも欲しいと思える内容か |
| **即効性** | 0〜10 | 10分以内に価値を得られるか |
| **商品との整合** | 0〜10 | 自然に有料サービスへの興味につながるか |
| **登録の手軽さ** | 0〜10 | フォームが簡単か（10＝メールアドレスのみ） |

**リードマグネットの効果順：**

1. テンプレート・ツール（最も転換率が高く、即座に価値がある）
2. チェックリスト・早見表（すぐ使えて理解しやすい）
3. 数値入りの事例集（信頼構築に効く）
4. 動画講座・勉強会（知覚価値が高い）
5. 電子書籍・ガイド（転換率は低いが権威づけに有効）
6. 診断・チェックツール（対話型で関与度が高い）
7. 無料体験・デモ（商品主導、最も購買意欲が高い）

**建設業で特に有効なリードマグネット：**

1. 「外壁塗装の費用相場と業者選びチェックリスト」（相場の不安に直接応える）
2. 「施工事例集PDF（費用・工期つき）」
3. 「無料現地調査＋見積もり」（最も強い。ただし営業色を消す文言が必須）
4. 「失敗しないリフォーム会社の選び方7か条」

## フェーズ3：ファネル指標とベンチマーク

### 3.1 主要指標

以下を算出（不明な場合は業界ベンチマークから推定）します。

```
ファネル指標
============

流入指標:
  月間訪問数  : [推定またはユーザーに確認]
  流入経路    : [自然検索%, 広告%, 参照%, 直接%, SNS%]

転換指標（建設業の標準値）:
  訪問 → 問い合わせ    : [X]%（目安 0.5〜2.0%）
  問い合わせ → 現地調査: [X]%（目安 40〜60%）
  現地調査 → 見積提出  : [X]%（目安 80〜90%）
  見積提出 → 契約      : [X]%（目安 20〜35%）
  訪問 → 契約（全体）  : [X]%（目安 0.05〜0.3%）

収益指標:
  平均受注単価      : [X]万円
  粗利率            : [X]%
  顧客生涯価値（LTV）: [X]万円（メンテ・追加工事・紹介を含む）
  顧客獲得単価（CAC）: [X]万円
  LTV:CAC 比率      : [X]:1（目標 3:1 以上）
  訪問者あたり粗利   : [X]円

関与指標:
  1訪問あたり閲覧ページ数: [X]
  平均滞在時間          : [X]分
  直帰率                : [X]%（目安 30〜60%）
```

### 3.2 訪問者あたり粗利の計算

ファネル最適化において最重要の指標です。

```
訪問者あたり粗利 = 月間粗利 ÷ 月間訪問数

例）建設業（外壁塗装）
  月間3,000訪問 × 訪問→成約率0.15% = 月4.5件
  4.5件 × 平均受注単価120万円 × 粗利率35% = 月間粗利 189万円
  訪問者あたり粗利 = 1,890,000円 ÷ 3,000 = 630円/訪問

問い合わせ率を1.0%から1.5%に改善した場合:
  月間3,000訪問 × 0.15%→0.225% = 月6.75件
  6.75件 × 120万円 × 35% = 月間粗利 283万円
  訪問者あたり粗利 = 945円/訪問
  粗利増 = 月94万円 = 年1,128万円
```

**注意：** 建設業は商談期間が数ヶ月〜1年に及ぶため、改善施策の効果が売上に表れるまで**3〜6ヶ月のタイムラグ**があります。試算には必ず期間を併記してください。

この枠組みで、すべての改善提案の効果を金額に換算します。

## フェーズ4：改善提案

### 4.1 優先順位マトリクス

すべての提案を以下の枠組みで格付けします。

| 優先度 | 効果 | 工数 | 実施時期 |
|---|---|---|---|
| **P1（すぐ実施）** | 高（10%以上の改善） | 低（1日未満） | 今週 |
| **P2（計画する）** | 高（10%以上の改善） | 中（1〜5日） | 今月 |
| **P3（予定に入れる）** | 中（5〜10%の改善） | 低（1日未満） | 今月 |
| **P4（後回し）** | 中（5〜10%の改善） | 高（5日以上） | 今四半期 |
| **P5（余裕があれば）** | 低（5%未満） | 問わず | リソースが空いたとき |

### 4.2 段階別の最適化施策

**ファネル上部（認知→興味）：**

- 見出しのA/Bテスト（想定改善 10〜30%）
- 社会的証明の配置改善（想定改善 5〜15%）
- 表示速度の最適化（想定改善 5〜20%）
- 離脱時ポップアップでの資料提供（離脱者の2〜5%を獲得）
- （建設業）施工事例を写真中心でトップに掲載（想定改善 10〜25%）

**ファネル中部（興味→検討）：**

- 事例・お客様の声ページの拡充（想定改善 10〜20%）
- 他社比較ページの作成（想定改善 5〜15%）
- 対話型のシミュレーター・診断（想定改善 15〜30%）
- 追客メールの導入（想定改善 10〜25%）
- （建設業）費用相場ページの新設（想定改善 15〜30%。最も検索される情報のため）

**ファネル下部（検討→成約）：**

- 費用・料金ページの再設計（想定改善 10〜25%）
- フォームの摩擦削減（想定改善 5〜15%）
- リスク解消（保証、無料点検）（想定改善 10〜20%）
- 緊急性・限定性の付与（想定改善 5〜15%）
- カゴ落ち・問い合わせ途中離脱の回復施策（離脱の5〜15%を回復）
- （建設業）工事保証・アフター体制の明示（想定改善 10〜20%）

**成約後（継続・拡大）：**

- 導入・着工前のフォローメール（解約・キャンセルを10〜20%削減）
- サンクスページでの追加提案（客単価の5〜15%向上）
- 紹介制度（新規顧客の5〜15%を創出）
- 30日後の満足度調査（離反リスクの早期発見）
- （建設業）OB顧客への定期点検案内（再受注と紹介の最大の源泉）

### 4.3 費用・料金ページの最適化

費用ページは最もレバレッジが効く改善ポイントです。

**チェックリスト：**

- [ ] 見出しがコストではなく価値を伝えている（「料金」ではなく「プランを選ぶ」）
- [ ] プランは3つ以内（または3つ＋法人向け）
- [ ] 1つのプランが「一番人気」「おすすめ」として強調されている
- [ ] 年額（またはまとめ払い）を先に表示し、割安額を明示している
- [ ] 機能説明が専門用語ではなくベネフィットで書かれている
- [ ] 料金付近に社会的証明がある（お客様の声、導入件数）
- [ ] 費用に関する上位5つの不安にFAQで答えている
- [ ] 返金保証または無料体験が目立つ位置にある
- [ ] プラン名が魅力的（「ベーシック／スタンダード」のような無機質な名称でない）
- [ ] CTAが行動を促す文言（「申し込む」ではなく「無料で相談する」）
- [ ] 競合との比較、または「導入しない場合のコスト」が示されている
- [ ] 迷っている人向けの「選び方ガイド」や診断がある

**建設業の場合は上記に加えて：**

- [ ] 施工事例ごとに実際の費用と工期が記載されている
- [ ] 「坪単価」「㎡単価」の目安が示されている
- [ ] 追加費用が発生するケースが正直に説明されている
- [ ] 見積もりが無料であること、しつこい営業をしないことが明記されている
- [ ] 助成金・補助金の情報がある（外壁塗装・断熱改修などで有効）

### 4.4 フォーム・申込フローの最適化

**摩擦の点検項目：**

- 入力項目の総数を数える（目安：問い合わせ3〜5、決済5〜8）
- 総ステップ数を数える（目安：最大1〜3ステップ）
- 複数ステップの場合、進捗表示があるか
- スマホでの入力しやすさ（入力種別の指定、自動補完、ボタンの大きさ）
- 不要な必須項目がないか
- 入力中にエラーが分かるか（リアルタイム検証）
- エラーメッセージが具体的か（「入力エラー」だけになっていないか）
- 途中保存して後から再開できるか
- （建設業）「電話で相談」の選択肢が同じ強さで並んでいるか

## フェーズ5：追客シーケンスとの連携

### 5.1 ファネル段階とメールの対応

各段階に適したメールシーケンスを提案します。

```
ファネル段階              → メールシーケンス
------------------------------------------------
訪問者（匿名）            → なし（リターゲティング広告を使う）
リード（登録済み）        → 歓迎シーケンス（5〜7通）
検討中のリード            → 追客シーケンス（6〜8通）
現地調査済み・見積提出済み → 検討支援シーケンス（4〜6通）
反応が止まった見込み客    → 掘り起こしシーケンス（3〜4通）
成約顧客                  → 着工前フォロー／アフターシーケンス
失注顧客                  → 再アプローチシーケンス（3〜4通）
OB顧客（建設業）          → 定期点検案内・季節の挨拶（年4〜6回）
```

### 5.2 流入経路との整合

流入経路によって、着地させるべきページが異なります。

| 流入経路 | 購買意欲 | 最適な着地点 | 推奨ファネル |
|---|---|---|---|
| 指名検索（社名） | 高 | お問い合わせ・費用ページ | 短い（直接コンバージョンへ） |
| 一般検索（地域名＋工種） | 中〜高 | 該当工種の専用ページ | 中程度（実績を見せてから誘導） |
| 一般検索（費用相場など） | 中 | 費用相場・お役立ち記事 | 中程度（情報提供してから誘導） |
| SNS広告 | 低〜中 | リードマグネット・事例 | 長い（獲得→追客→成約） |
| 紹介・口コミ | 中〜高 | トップページ・事例ページ | 中程度（信頼は構築済み） |
| 直接流入 | 高 | トップページ | 短い（既に認知あり） |
| Googleマップ | 高 | トップまたは電話 | 最短（電話導線を最優先） |
| メール | 中 | 内容に対応した個別ページ | メールの話題に合わせる |

## 他スキルとの連携

- `MARKETING-AUDIT.md` があれば、コンバージョンスコアを参照する
- `COPY-SUGGESTIONS.md` があれば、その改善案をファネル各ページに適用する
- `EMAIL-SEQUENCES.md` があれば、ファネル段階との整合を確認する
- `COMPETITOR-REPORT.md` があれば、競合のファネルと比較する
- 深掘り用に `/market copy`（ページ単位のコピー）、`/market emails`（追客シーケンス）、`/market landing`（CRO詳細）を提案する
