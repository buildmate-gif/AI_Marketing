# market-competitors — 実データの取得手順

競合分析で最も価値が低いのは「おそらくこうだろう」という推測です。この節では、**実際に確認できる数字**を取りに行く手順を示します。推測で埋めた比較表は、クライアントに見抜かれます。

## 原則

| やること | やらないこと |
|---|---|
| 検索して実際の順位を数える | 「上位表示されていると思われる」と書く |
| クチコミ件数と評点を目視で確認する | 「評判は良さそう」と書く |
| 施工事例の掲載件数を数える | 「実績は豊富」と書く |
| 取得できなかった項目は「未取得」と書く | 空欄を推測で埋める |

**確認できなかった項目は、正直に「未取得」と記載してください。** 推測を事実のように並べたレポートは、1箇所でも誤りが見つかった時点で全体の信頼を失います。

---

## 1. 地図検索順位の実測（建設業で最重要）

建設業では、Googleマップの上位3枠（ローカルパック）に入れるかどうかが問い合わせ数を左右します。

### 手順

1. `WebSearch` または ブラウザツールで「[市区町村名] [工種]」を検索する
   - 例：「豊中市 外壁塗装」「岡崎市 屋根修理」
2. 地図結果に表示される事業者を、上から順に記録する
3. 各社について、以下を記録する
   - 表示順位
   - クチコミ件数
   - クチコミ評点
   - 表示されている業種カテゴリ

### 記録する形式

```markdown
検索キーワード：「〇〇市 外壁塗装」（検索日：2026-07-25）

| 順位 | 事業者名 | クチコミ | 評点 | カテゴリ |
|---|---|---|---|---|
| 1 | △△塗装工業 | 86件 | 4.5 | 塗装業者 |
| 2 | □□ホーム | 42件 | 4.7 | リフォーム業者 |
| 3 | ××建装 | 33件 | 4.2 | 塗装業者 |
| … | | | | |
| 12 | **[対象社]** | 12件 | 3.8 | 建設会社 |
```

### 検索するキーワードの組み合わせ

対象社の主力工種と対応エリアに応じて、最低5パターンは実測してください。

- 「[市区町村] [主力工種]」
- 「[市区町村] [工種] おすすめ」
- 「[市区町村] [工種] 安い」
- 「[隣接市区町村] [主力工種]」
- 「[工種] 業者 [市区町村]」

**順位は検索する場所によって変わります。** 実測した条件（検索日、キーワード）を必ずレポートに明記してください。

## 2. Googleビジネスプロフィールの実測

各競合について、以下を確認します。ブラウザツールで店舗情報ページを開くのが確実です。

| 確認項目 | 見る場所 |
|---|---|
| クチコミ件数・評点 | プロフィール上部 |
| 写真の枚数 | 「写真」タブ |
| 投稿の頻度 | 「最新情報」タブの日付 |
| クチコミへの返信率 | クチコミ一覧を10件ほど確認し、返信の有無を数える |
| 登録カテゴリ | プロフィールの業種表記 |
| 営業時間の設定 | プロフィール |
| ウェブサイトのリンク | プロフィール |

### クチコミ本文の分析

**件数と評点だけでなく、本文を読んでください。** ここに最も価値のある情報があります。

各競合について、直近のクチコミを10件ほど読み、以下を抽出します。

- **褒められている点 上位3つ** — 顧客が何に価値を感じているか
- **不満として挙がっている点 上位3つ** — そのまま自社の訴求点になります
- **他社から乗り換えた理由** — 「前の業者は〜だった」という記述

例えば「工期が延びた」という不満が複数社で見られる地域なら、「工期厳守」を前面に出すのが有効です。これは推測では絶対に出てこない材料です。

## 3. 検索順位の実測

自然検索（地図ではない通常の検索結果）の順位も確認します。

1. `WebSearch` で対象キーワードを検索する
2. 上位10件のドメインを記録する
3. 対象社が何位にいるか、いなければ「圏外」と記録する

```markdown
| キーワード | 1位 | 2位 | 3位 | 対象社 |
|---|---|---|---|---|
| 〇〇市 外壁塗装 | 一括見積もりサイト | △△塗装 | □□ホーム | 14位 |
| 外壁塗装 費用 〇〇市 | 一括見積もりサイト | ××建装 | △△塗装 | 圏外 |
```

**一括見積もりサイトが上位を占めている場合、それが最大の競合です。** 「地域の同業者より、ポータルサイトに顧客を取られている」という事実は、クライアントにとって最も重要な発見になり得ます。

## 4. 競合サイトの実測項目

各競合サイトを実際に開いて、以下を数えます。推測しないこと。

| 項目 | 数え方 |
|---|---|
| 施工事例の掲載件数 | 事例一覧ページの件数を数える |
| 費用の記載 | 金額が書かれているか、「お問い合わせください」のみか |
| 事例への費用・工期の記載 | 事例を3件開いて確認する |
| 建設業許可番号の記載 | サイト内検索、なければフッターと会社概要を確認 |
| 保証年数 | 記載があれば年数、なければ「記載なし」 |
| 対応エリアの粒度 | 都道府県単位か、市区町村単位か |
| スタッフの顔写真 | 会社概要ページで確認 |
| 電話番号のヘッダー固定 | トップページを開いて確認 |
| LINE相談の有無 | トップページとフッターを確認 |
| ブログの最終更新日 | ブログ一覧の最新記事の日付 |
| Instagram のフォロワー数 | リンクから実際に開いて確認 |

**ブログの最終更新日は特に有用です。** 半年以上更新が止まっている競合は、Web集客に力を入れていない証拠です。

## 5. 広告出稿状況の確認

競合が広告を出しているかは、以下で確認できます。

- **Meta広告ライブラリ** — Facebook/Instagram の広告を誰でも閲覧できます
- **Google 広告の透明性センター** — 出稿中の広告を確認できます
- 検索結果の広告枠 — 実際に検索して、広告表示されている事業者を記録する

広告を出している競合がいるかどうかで、その地域の獲得単価の相場が推測できます。

---

## 6. 取得できなかった場合の書き方

以下のように、正直に記載してください。

```markdown
| 項目 | 対象社 | 競合A | 競合B |
|---|---|---|---|
| クチコミ件数 | 12件 | 86件 | 未取得（プロフィール非公開） |
| 月間広告費 | 未取得 | 未取得 | 未取得 |
```

**「未取得」と書くことを恐れないでください。** クライアントは、正直な「分かりません」を、もっともらしい推測より高く評価します。

---

## 実測データのレポートへの反映

実測した数字は、必ず以下をセットで記載してください。

- 取得日
- 取得方法（検索キーワード、確認したページ）
- 取得できなかった項目とその理由

これにより、次回の `/market track` で同じ条件で測り直せるようになり、推移が語れるようになります。
