# market-ads — 予算配分・獲得単価・ROAS・着地ページ整合

## フェーズ4：予算と成果指標

### 4.1 配分と検証

商圏、目的、試せる予算、実測した検索需要、既存施策の獲得単価を確認します。予算合計と期間を固定し、小さく検証できる媒体数に絞ります。比較表には費用、有効問い合わせ、受注、対象期間を記載し、数値の出所を添えます。

### 4.2 許容問い合わせ単価と実績

許容問い合わせ単価は「1受注に使える広告費 × 問い合わせからの成約率」で試算します。成約率が不明な場合は初回検証と必要なデータを提案します。GA4の問い合わせ送信完了、CRMの有効商談・受注、広告管理画面の成果を区別します。Google広告に商談や受注を取り込む構想にはData Managerなど現行の経路と利用条件を確認し、提案資料には集計値を使います。[GA4推奨イベント](https://support.google.com/analytics/answer/9267735?hl=ja)・[Google広告の計測仕様](https://support.google.com/google-ads/answer/16884284)


**建設業での判断基準：** 問い合わせ単価が3万円でも、成約率25%・平均受注単価120万円・粗利35%であれば、1件の受注につき広告費12万円で粗利42万円が得られます。**問い合わせ単価だけを見て高い・安いを判断しないでください。**

```
1受注あたりの広告費 = 問い合わせ単価 ÷ 成約率
                     = 30,000円 ÷ 25% = 120,000円

1受注あたりの粗利 = 平均受注単価 × 粗利率
                   = 1,200,000円 × 35% = 420,000円

差引利益 = 420,000円 − 120,000円 = 300,000円（十分に成立する）
```

売上ROASは広告経由の売上 ÷ 広告費として期間と売上の帰属条件を併記します。粗利で評価する案件には別項目を設けます。

### 4.3 着地ページとの整合

各キャンペーンについて、着地ページとの整合を確認します。

**確認項目：**

- 着地ページの見出しが広告の見出しと一致しているか
- 着地ページが広告の約束を果たしているか
- 着地ページのCTAが広告のCTAと一致しているか
- 広告とページのデザインの雰囲気が揃っているか
- 着地ページがスマホ最適化されているか（SNS広告では必須）
- 着地ページが3秒以内に表示されるか
- コンバージョン行動が1つに絞られているか
- （建設業）電話番号がタップで発信できるか

**整合スコア：** 各広告と遷移先ページの一致度を1〜10で評価し、7未満は要改善として明示します。
