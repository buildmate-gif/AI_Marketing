# market-visual — 視覚採点の基準

撮影したスクリーンショットを見て、6項目を各100点で採点します。**必ず画像を実際に見て判断してください。** HTMLの内容から推測して採点しないこと。

## 総合スコアの算出

```
ビジュアルスコア = (
    ファーストビューの印象 × 0.25 +
    写真・画像の質         × 0.25 +
    スマホでの見え方       × 0.20 +
    情報設計と余白         × 0.15 +
    CTAの視認性            × 0.10 +
    デザインの新しさ       × 0.05
)
```

建設業では「写真の質」の配点を高く取っています。施工写真がそのまま受注に直結するためです。

---

## 1. ファーストビューの印象（配点25%）

**評価の問い：** この1枚だけを3秒見せられて、「何の会社か」「自分に関係あるか」「次に何をすればいいか」が分かるか。

| 点数 | 状態 |
|---|---|
| 90〜100 | 業種・地域・強み・次の行動が一目で伝わる。写真が印象的で、視線が自然にCTAへ向かう |
| 70〜89 | 何の会社かは分かるが、地域か強みのどちらかが弱い |
| 50〜69 | 業種は分かるが、他社と区別がつかない。汎用的な印象 |
| 30〜49 | 何の会社か判断に数秒かかる。文字が多すぎるか、逆に情報が無い |
| 0〜29 | 意味が分からない。素材写真だけ、またはスライダーが動いていて内容が読めない |

**減点する具体的な問題：**

- 自動で切り替わるスライダーで、読む前に画像が変わる
- クッキー同意バナーやチャットウィジェットが画面の3割以上を隠している
- 文字が背景写真に重なって読めない（コントラスト不足）
- 会社の外観写真だけで、何をする会社か分からない
- 「快適な暮らしを」のような、どの会社でも言える文言だけ

**建設業で加点する要素：**

- 施工前後が対比できる写真
- 対応エリアが文字で明示されている
- 実績数値（「施工実績1,200件」など）が見える位置にある
- 電話番号が大きく、タップできる位置にある

---

## 2. 写真・画像の質（配点25%）

**評価の問い：** 掲載されている写真は、この会社に頼みたいと思わせるか。

| 点数 | 状態 |
|---|---|
| 90〜100 | 自社撮影の施工写真が豊富。明るく、構図が整い、施工前後が対比されている |
| 70〜89 | 自社写真はあるが、明るさや構図にばらつきがある |
| 50〜69 | 自社写真が少なく、素材写真が混在している |
| 30〜49 | ほぼ素材写真。または写真が暗い・ぶれている・小さい |
| 0〜29 | 写真がほとんど無い。またはイラストのみ |

**確認する点：**

- 素材写真か自社撮影か（外国人モデルの写真は建設業では逆効果です）
- 明るさ（曇天や逆光の写真は印象を大きく損ないます）
- 構図（斜めに傾いていないか、電線や車が入り込んでいないか）
- 施工前後の対比が同じ角度・同じ条件で撮られているか
- 職人・スタッフの顔写真があるか（建設業では信頼に直結します）
- 写真の解像度（引き伸ばしてぼやけていないか）
- 画像の読み込みが遅すぎないか（撮影時に体感した表示速度も記録する）

---

## 3. スマホでの見え方（配点20%）

**評価の問い：** スマホのスクリーンショットだけを見て、PCと同等以上に使いやすいか。

| 点数 | 状態 |
|---|---|
| 90〜100 | スマホ前提で設計されている。電話ボタンが常時表示。文字が読みやすい |
| 70〜89 | 問題なく使えるが、一部で文字が小さいか要素が詰まっている |
| 50〜69 | PC版をそのまま縮小した印象。指で押しづらい箇所がある |
| 30〜49 | 横スクロールが発生する、または文字が拡大しないと読めない |
| 0〜29 | レイアウトが崩れている。実用に耐えない |

**減点する具体的な問題：**

- 本文の文字が16px未満に見える
- ボタン同士が近接していて誤タップしそう
- 電話番号が画像になっていてタップできない
- ファーストビューがロゴとメニューだけで埋まり、内容が見えない
- 表が画面をはみ出している
- メニューが開けない、または開くと画面全体を覆って閉じられない

---

## 4. 情報設計と余白（配点15%）

**評価の問い：** 全体を眺めたときに、視線が迷わず流れるか。

| 点数 | 状態 |
|---|---|
| 90〜100 | 余白が十分。1画面に1メッセージ。見出しと本文の階層が明確 |
| 70〜89 | 概ね整理されているが、一部に詰め込みがある |
| 50〜69 | 情報量が多く、どこを見ればいいか迷う |
| 30〜49 | 詰まりすぎ。色数が多く、視線が散る |
| 0〜29 | 情報が羅列されているだけ。構造が読み取れない |

**確認する点：**

- 使われている色は3〜4色に収まっているか
- 書体が2種類以内か
- 見出しと本文のサイズ差が明確か
- 横幅いっぱいに文字が伸びていないか（1行45文字以内が読みやすい）
- 赤字・太字・下線・マーカーが乱用されていないか
- セクションの区切りが分かるか

---

## 5. CTAの視認性（配点10%）

**評価の問い：** スクリーンショットを薄目で見たとき、どこを押せばいいか分かるか。

| 点数 | 状態 |
|---|---|
| 90〜100 | CTAが背景と明確に対比し、余白で囲まれ、一目で見つかる |
| 70〜89 | 見つかるが、周囲の要素と競合している |
| 50〜69 | 探せば見つかる程度。目立たない |
| 30〜49 | 他のリンクと区別がつかない |
| 0〜29 | ファーストビュー内にCTAが無い |

**確認する点：**

- CTAの色が背景・周囲と十分に対比しているか
- 同じ強さのボタンが並んでいないか（優先順位が無い状態）
- CTAの周りに余白があるか
- スクロール時に追従するCTAがあるか
- ポップアップやチャットがCTAを隠していないか

---

## 6. デザインの新しさ（配点5%）

**評価の問い：** 見た目が何年頃のサイトに見えるか。

| 点数 | 状態 |
|---|---|
| 90〜100 | 現在の標準的な水準。古さを感じない |
| 70〜89 | やや古いが違和感は無い |
| 50〜69 | 5年ほど前の印象 |
| 30〜49 | 10年前の印象。グラデーション、影、立体的なボタンが目立つ |
| 0〜29 | 明らかに古い。テーブルレイアウト、点滅、背景タイル画像 |

**古く見える典型的な要素：**

- ボタンに強い立体感・グラデーション・影
- 角丸が過剰、または全く無い
- 背景に模様のあるタイル画像
- 文字に袋文字・影・光彩がかかっている
- アニメーションGIF
- 「NEW!」マークの点滅
- サイドバーに大量のバナーが縦に並んでいる

**注意：** 建設業では「今風だが冷たい」より「やや古いが誠実」の方が高齢の施主層に響く場合があります。デザインの新しさの配点を5%に抑えているのはこのためです。**古い＝即改善すべき、と短絡しないでください。** 顧客層を踏まえて判断し、レポートにその旨を書いてください。

---

## 採点時の絶対的なルール

1. **見ていないものを採点しない。** 撮影できなかったページは「未確認」と明記する
2. **具体的な根拠を書く。** 「デザインが古い」ではなく「ボタンに強いグラデーションと影が使われており、10年前の印象を与えている」と書く
3. **どのスクリーンショットの何を見て判断したかを示す。** 「スマホ版ファーストビューで、電話番号が画面外にあった」のように
4. **改善案は必ず具体的に。** 「写真を良くする」ではなく「施工事例の写真を、晴天日の午前中に、正面から水平を出して撮り直す。施工前と同じ角度で揃える」と書く
