# market-visual — ブラウザでの撮影手順

## 手順1：ブラウザを開く

```
mcp__Claude_Browser__preview_start（url に対象URLを指定）
```

開けない場合は `mcp__Claude_Browser__navigate` でURLを指定します。読み込みが終わるまで数秒待ってから撮影してください。**読み込み途中のスクリーンショットで採点しないでください。**

## 手順2：PC表示の撮影

```
mcp__Claude_Browser__resize_window（preset: "desktop" = 1280×800）
mcp__Claude_Browser__computer（action: "screenshot"）
```

これがファーストビューです。**訪問者が最初の3秒で見る唯一の画面**として評価します。

続いてページ全体を見るため、下方向にスクロールしながら複数枚撮影します。

```
mcp__Claude_Browser__computer（action: "scroll", scroll_direction: "down", scroll_amount: 5）
mcp__Claude_Browser__computer（action: "screenshot"）
```

これをページ末尾まで繰り返します。トップページは通常4〜8枚で全体が収まります。

## 手順3：スマホ表示の撮影

```
mcp__Claude_Browser__resize_window（preset: "mobile" = 375×812）
mcp__Claude_Browser__computer（action: "screenshot"）
```

同様にスクロールしながら撮影します。**建設業のサイトは訪問者の7割以上がスマホです。** PC表示だけで評価を終えないでください。

スマホでは特に以下を確認します。

- ファーストビューに何が入っているか（PCで見えていた要素が押し出されていないか）
- 電話番号がタップできる位置にあるか
- 文字が小さすぎないか
- 横スクロールが発生していないか
- ボタンが指で押せる大きさか

## 手順4：重要ページの撮影

トップページ以外に、以下があれば必ず撮影します。

| ページ | 撮影する理由 |
|---|---|
| 施工事例・実績ページ | 建設業で最も重要。写真の質と並べ方を見る |
| 費用・料金ページ | 金額の見せ方と、価格ショックの有無 |
| お問い合わせフォーム | スマホでの入力しやすさ。項目数を目視で数える |
| 会社概要 | 代表・スタッフの写真の有無と印象 |

各ページへは `mcp__Claude_Browser__navigate` で移動します。ページの一覧が不明な場合は、先に `mcp__Claude_Browser__read_page` でナビゲーションのリンクを確認してください。

## 手順5：ダークモードの確認（任意）

```
mcp__Claude_Browser__resize_window（colorScheme: "dark"）
```

ダークモード指定でレイアウトが崩れるサイトがあります。時間に余裕があれば確認してください。

## 撮影時の注意

- **クッキー同意バナーが出ている場合**、それがファーストビューをどれだけ隠しているかも評価対象です。まず隠された状態で1枚撮り、その後閉じてから本来の画面を撮影してください
- **チャットウィジェットや広告ポップアップ**も同様に、出た状態で1枚撮ります。これらがCTAを隠していることは非常に多い
- 撮影できなかったページがあれば、レポートに明記してください。推測で補完しないこと

## 撮影できない場合

以下の状況ではブラウザツールが使えません。その場合は正直に報告し、代替案を示してください。

| 状況 | 代替案 |
|---|---|
| ブラウザツールが利用できない | ユーザーにスクリーンショットの提供を依頼する |
| 会員限定・ログインが必要 | Claude in Chrome での閲覧を提案する、または公開部分のみ評価する |
| サイトがアクセスを拒否している | URLの確認を促し、テキストベースの `/market landing` を提案する |
