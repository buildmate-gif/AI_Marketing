# 顧客向け月次報告

`track_history.py report` で日付、診断スコア、施策ごとの最終記録、実測値、比較条件を出力する。対象案件の `TRACK-REPORT.md` の冒頭に、次の順序で要点を加える。

1. **対象期間と結論**。診断の実施日と指標の集計期間を明記する。初回は比較の基準値を示す。
2. **実施したこと**。施策 ID、該当ページ、実施状況とその根拠。最終記録が以前の月の場合は確認日を残す。
3. **観測した変化**。比較可能な指標には前後の数値・単位と差を示す。未計測や条件変更がある場合は、その理由と次回の取得先を記す。
4. **次の施策**。最大3件について、担当者が着手する変更、追う指標、次回確認時期を書く。

例（架空）。「9月と10月の問い合わせ台帳では6件から8件に増えました。10月7日に施工事例へ相談ボタンを追加しました。流入元ごとの件数は未計測です。次回は同意の範囲内でボタン経由の問い合わせを識別し、他経路と合わせて確認します。」

実測の売上・粗利に触れる際は、会計資料の対象期間と出所を明記する。仮定を使って換算した金額には、仮定・計算過程・試算である旨を併記する。施策単独の寄与を検証できた場合だけ、その効果を金額で示す。
