# market-track — TRACK-REPORT.md の書式

`track_history.py report` の出力に考察を加えて、以下の形式でまとめます。

```markdown
# マーケティング推移レポート：[会社名]

**対象URL：** [url]
**測定回数：** [X] 回
**期間：** [初回日] 〜 [最新日]
**今回の総合スコア：[X]/100（前回比 ▲[X]点、初回比 ▲[X]点）**

---

## エグゼクティブ・サマリー

[3〜4段落。この期間で何が変わったか、どの施策が効いたか、
実測値がどう動いたか、次の期間に何をすべきか。
経営者が最初の1段落だけ読んでも状況が分かるように書く]

---

```

## スコアと実測値の整合

[スコアは上がっているのに問い合わせが増えていない、あるいはその逆の場合、
必ず原因を考察する。整合している場合も、その旨を書く]

例：
- スコアと問い合わせ件数がともに上昇 → 施策が想定どおり機能している
- スコアは上昇したが問い合わせは横ばい → 流入自体が増えていない可能性。
  SEOと広告の見直しが必要
- 問い合わせは増えたが受注は横ばい → サイトではなく商談プロセスに課題がある

## 次の期間に取り組むこと

現在最も低いカテゴリと、実測値の伸び悩みから導きます。

1. **[施策]** — [根拠となるスコア・実測値] / 想定効果 月[X]万円 / 実施期間 [X]週間
2. **[施策]** — [根拠] / 想定効果 / 実施期間
3. **[施策]** — [根拠] / 想定効果 / 実施期間

**効果が表れる時期：** 今回の期間に実施した施策の効果は、建設業の商談サイクル（3〜6ヶ月）を踏まえると、次回または次々回の測定に表れます。
