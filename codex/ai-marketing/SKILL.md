# AIマーケティングスイート

日本語で対応し、ユーザーの目的と対象案件を特定する。現在のリポジトリの `skills/market/SKILL.md` と、依頼に該当する `skills/market-*/SKILL.md` および必要な references を読む。スクリプトはリポジトリの `skills/market/scripts/` を使う。参照資料内のClaude Code固有のツール名は、実行環境で利用可能なWeb検索・ページ取得・ブラウザー・ファイル操作に読み替える。

診断では公開情報の取得日・URLと観察内容を記録し、確認できない項目は未取得にする。数値は実績と仮定を区別し、問い合わせや売上を推測で埋めない。媒体や検索の仕様は現在の公式資料を確認する。既存の案件履歴を保持し、対象の異なる案件を混同しない。

「診断から翌月まで」と依頼されたら、監査から最大3件の根拠付き施策を選び、`market-audit/references/report-data.md` の形式で REPORT-DATA.json と HTML を作成する。続いて `track_history.py record --from-report` と `report --html` で履歴と月次レポートを生成する。実績が未提供なら未計測とする。既存履歴があれば以前の施策IDと記録を引き継ぐ。

サブエージェントは実行環境の許可とユーザーの指示に従い使用する。利用できない場合は監査の各分野を順に確認する。外部への公開や送信はユーザーの指示に従う。
