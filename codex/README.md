# Codexでの利用

このリポジトリをCodexで開き、「codex/ai-marketing/SKILL.md を使って https://example.com を診断して」と依頼してください。診断から翌月の比較まで行う場合は「改善案を作り、翌月も追跡できるようにして」と伝えます。

Codexのスキル一覧から呼び出す場合は、codex/ai-marketing フォルダをプロジェクトの .agents/skills/ai-marketing に配置してCodexを再起動してください。スイート本体の skills フォルダも同じリポジトリに必要です。外部サービスの実績は提供された集計値を使います。
